# 项目图片目录

网站当前使用以下真实素材。后续替换同名文件即可更新图片；如新增项目，请同时修改 `app/data/portfolio.ts` 中的路径与替代文本。

```text
public/
├── images/
│   └── portrait.jpg
└── projects/
    ├── scada-content-operations/
    │   ├── cover.jpg
    │   └── results.jpg
    ├── ai-video-production/
    │   ├── cover.jpg
    │   └── workflow.png
    ├── student-film-projects/
    │   ├── 007-behind-the-scenes.png
    │   └── may-rain.png
    └── photography/
        ├── photo-01.jpg
        ├── photo-02.jpg
        └── photo-03.jpg
```

建议：封面使用 JPG/WebP，数据截图与界面截图可使用 PNG；新增大图时尽量把最长边控制在 2400px 左右，并确认已获得公开展示授权。
